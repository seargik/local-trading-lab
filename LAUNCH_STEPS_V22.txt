LOCAL LAB V22 — launch steps

1) Unzip the package.
2) Open PowerShell in the project folder.
3) Install / update dependencies:
   py -3 -m venv .venv
   .\.venv\Scripts\python.exe -m pip install --upgrade pip
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt

4) Start the backtest worker:
   .\start_backtest_worker.bat

5) Start the separate backtest app:
   .\start_backtest_only.bat

6) If port 8503 is busy, run:
   .\.venv\Scripts\python.exe -m streamlit run .\backtest_app.py --server.port 8504

7) Optional main app:
   .\start_all_windows.bat
